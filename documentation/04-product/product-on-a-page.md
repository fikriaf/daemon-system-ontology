# Product on a page

## Problem

A reference logistics organization runs complex ops and finance across branches and legal entities. Data is fragmented; IPO narrative requires audit-ready, consistent entities.

## Solution

**Ontology-first platform** with two primary product surfaces:

1. **Ops Control Tower** — live shipments, exceptions, network health
2. **Financial Governance** — interco, transfer pricing tags, elimination workflow

Plus an **agent** that operates as a power user: observes ontology state, proposes governed actions, never bypasses audit.

## Users

| Persona | Primary surface |
|---------|-----------------|
| Branch / hub ops | Ops tower |
| Finance / interco | Finance home, Interco console |
| Leadership | KPI command views |
| Agent (assisted) | Proposals in context of same screens |

## Success (Wave 1)

Core ontology live; six MVP screens; agent suggest-only with HITL.
